# Emblem art

The symbols are icons from [game-icons.net](https://game-icons.net), licensed under
[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). `symbols.csv` lists every symbol's id,
icon name and author. Authors of the icons used: Lorc, Delapouite, Sbed, Caro Asercion, Cathelineau,
DarkZaitzev, Kier Heyl, Pepijn Poolman, Skoll and Sparker.

`symbols/emblem_NN.png` are generated by `tools/make_symbols.ps1` from the site's PNG archive
(white on transparent), which the script downloads to `source/game-icons.net.png.zip` when missing;
the archive is gitignored. Each icon is cropped to its shape, centred, and scaled so its larger
side spans 80% of a 256 x 256 canvas, so every symbol comes out the same visual size on the banner.

The icons were picked from those that are close to mirror-symmetric: the banner cloth shows the
left half of its texture twice, so a profile view (an animal facing sideways) would come out as a
two-headed mirror image.

The mod uses only the images' alpha and fills the shape with the banner's flat symbol colour.

The order of the list in `tools/make_symbols.ps1` is the symbol id players type and banners store.
Never reorder or remove entries once released; append new icons at the end, regenerate, and commit
the PNGs and `symbols.csv` with the script change.
